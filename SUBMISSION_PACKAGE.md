## 🚀 **Demo Instructions:**

### **Quick Start:**
1. Install dependencies: `python setup.py`
2. Add API key to `.env` file: `GEMINI_API_KEY=your_key`
3. Run demo: `python main.py demo`
4. Launch dashboard: `python -m streamlit run streamlit_app.py`

### **Full Pipeline:**
```bash
# Complete analysis
python main.py pipeline --data your_data.csv

# Interactive interfaces  
python main.py interface --interface streamlit
python main.py interface --interface cli

# Easy launcher
.\run_with_ai.bat
```
